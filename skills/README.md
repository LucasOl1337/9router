# Agent skills do 9Router

A família de skills `9router*` mantida por LucasOL agora tem uma única fonte:
[`LucasOl1337/LucasOl-Skills`](https://github.com/LucasOl1337/LucasOl-Skills/tree/main/skills).

Para expô-las no hub local, clone o repositório central e execute:

```bash
python scripts/install_skills.py --replace
python scripts/install_skills.py --check
```

O código e a documentação do gateway permanecem neste repositório; somente as
cópias das skills foram removidas.
